03Environment debugging

Resolved the runtime mismatch

The laptop’s default Python 3.14 did not fit the pinned scientific stack, and PyArrow 26 conflicted with NumPy 1.26. The project was run under Python 3.12 with PyArrow pinned to 19.0.1.

Python 3.12 · PyArrow 19.0.1
04First full pass

Found and fixed a notebook setting

The initial pass completed the 5.6-million-row scan and evaluation, then stopped because the Morris explainer setting was missing. Added the setting and an ignored sample cache so later cells can resume without rescanning.

Configuration fixed · cache added
05Full execution · AWS

Ran every notebook section

Used a temporary, small AWS compute instance for the long streaming scan. The completed run generated global and local explanations, feature-space what-if rows, figures, and reports with no errored notebook cells.

5,615,820 RAID rows scanned
06Delivery

Retrieved and published the outputs

Copied the executed notebook and results into the workspace, kept raw sample text in the ignored local cache, and prepared the repository with evaluation artifacts and this build log.

What was produced

Global sensitivity

Morris sensitivity and partial dependence summaries across the eight numeric features.

Local case studies

LIME and Kernel SHAP approximations for available correct and misclassified outcomes.

Feature-space what-if

One-at-a-time changes at observed 10th, 50th, and 90th percentile values.

These explanations describe model behavior on this sample. They are not causal claims, text-span explanations, or evidence of who authored an individual passage.

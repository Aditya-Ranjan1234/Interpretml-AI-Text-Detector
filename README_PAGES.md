# GitHub Pages presentation

Open `index.html` directly or publish this repository root to GitHub Pages. It is a static SPA with no build step and no backend dependency.

Run the local integrity check from PowerShell:

```powershell
.\verify.ps1
```

The presentation uses the committed evaluation facts: 60.99% accuracy, AI precision 59.66%, recall 67.90%, F1 63.51%, ROC-AUC 0.645, and the 2×2 confusion matrix. The what-if lab is deliberately labelled as an illustrative feature-space perturbation, not a causal model or authorship test.
